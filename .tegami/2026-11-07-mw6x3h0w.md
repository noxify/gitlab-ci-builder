## Child pipeline visualization fixes, new sync extractor, dependency and audit updates

This release fixes several child pipeline visualization bugs, adds a synchronous child pipeline extractor, and updates dependencies and security overrides. The public API stays backwards compatible.

**New:**

- Added `extractChildPipelinesSync`, a synchronous variant of `extractChildPipelines`. The async `extractChildPipelines` is unchanged and still returns a `Promise`.

**Fixed:**

- Child pipelines are now rendered correctly in all visualization outputs. Previously `generateMermaidDiagram`, `generateAsciiTree`, and `generateStageTable` dropped child pipeline content because the extraction ran asynchronously and was never awaited.
- Mermaid diagrams now apply the `:::job` class to jobs without a stage, draw a dotted edge (`-.->`) for unresolved `extends` targets, and the stage table shows the full transitive `extends` chain (e.g. `build ← .build ← .base`) instead of only the direct parent.
- `childPipeline()` no longer emits `strategy: undefined` / `forward: undefined` keys on the generated trigger when those options are not provided.

**Internal:**

- `visualizeYaml` moved into its own module to break a circular dependency and remove ineffective dynamic imports from the build. It remains exported from the package root, so imports do not change.
- Updated all dependencies to their latest versions and compatibility with the new `js-yaml` and `msw` majors.
- Refreshed `pnpm` security overrides (shell-quote, vite, source-map-js, hono, @hono/node-server, zod) and removed stale overrides. All actionable `pnpm audit` findings are resolved; one non-fixable low-severity advisory in a dev-only transitive dependency is acknowledged.
